# ICRAE2026
Supplementary Material to "Generative AI in PLC Programming: A Human--AI Collaboration Benchmark Study"
## Booklet Structure and Sequence Groups

The study uses four booklets, labeled **A–D**, to assign participants to four different sequence groups. The booklets vary the order of tasks and the order of the experimental conditions in order to counterbalance possible order effects.

Each booklet contains two tasks, performed either **with Engineering Copilot** or **without Engineering Copilot**.

| Booklet | First task                         | Second task                        | Purpose                                                  |
| ------- | ---------------------------------- | ---------------------------------- | -------------------------------------------------------- |
| A       | Task 1 with Engineering Copilot    | Task 2 without Engineering Copilot | Sequence 1                                               |
| D       | Task 2 without Engineering Copilot | Task 1 with Engineering Copilot    | Same task-condition combination as A, but reversed order |
| B       | Task 2 with Engineering Copilot    | Task 1 without Engineering Copilot | Sequence 2                                               |
| C       | Task 1 without Engineering Copilot | Task 2 with Engineering Copilot    | Same task-condition combination as B, but reversed order |

Thus, booklets **A and D** contain the same task-condition combination, but in reversed order. The same applies to booklets **B and C**. This design allows the order of tasks and conditions to vary across groups.
